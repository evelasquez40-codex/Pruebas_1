# Guía SCORM Universal

Convierte el conocimiento del skill `scorm-english` (específico de inglés/HSC) en un método **genérico** para construir cualquier lección interactiva empaquetable como SCORM 1.2, independiente de materia, grado o marca.

- **`GUIA-SCORM-UNIVERSAL.md`** — la guía completa: arquitectura del motor, catálogo de 19 mecánicas interactivas, envoltorio pedagógico, persistencia SCORM (usuario, tiempo, reanudación, nota parcial), accesibilidad, errores reales a evitar y checklist de entrega.
- **`templates/index-skeleton.html`** — SCO funcional de una sola página (probado en navegador real: navegación, 3 mecánicas de ejemplo, puntaje, guardado y reanudación) listo para copiar y reemplazar solo los datos.
- **`templates/imsmanifest.xml`** — manifiesto SCORM 1.2 genérico.

## Cómo usarla

Cita esta guía al pedir una lección (a un asistente de IA o como tu propio checklist):

> "Usando `scorm-universal-guide/GUIA-SCORM-UNIVERSAL.md` y `templates/index-skeleton.html`, construye una lección SCORM 1.2 sobre **[tema]** para **[público]**, con **[N]** actividades del catálogo de mecánicas, envoltorio pedagógico completo y persistencia SCORM, siguiendo el checklist de entrega antes de dar el ZIP final."

Ver la sección 9 de la guía para más detalle.
